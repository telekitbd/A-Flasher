# Attribution

This app is distributed with credit links to its original author/community
(see the in-app Credits button). Please keep these links intact if you
redistribute this project or a build of it.

Release builds produced by the project owner's own signing key (see the
`RELEASE_KEYSTORE_*` GitHub Actions secrets) can be identified by their
signing certificate fingerprint. A rebuilt or modified copy signed with a
different key is not an official build of this app, whatever package name
or UI it keeps.
